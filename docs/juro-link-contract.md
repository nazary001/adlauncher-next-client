# JURO link — как кнопкой передавать кампании в Ad Launcher (режим JURO)

Инструкция для внешнего инструмента (статистика / дашборд): как кнопка **JURO** должна
открывать наш лаунчер, чтобы кампании попали на HS-борд **сразу в режиме JURO**.

Коротко: **передаём только ID кампаний-источников**, всё остальное лаунчер подтягивает сам.
JURO берёт **посты фанки** каждой переданной кампании и рождает НОВУЮ кампанию с ads на
странице поста (соушл-прув поста сохраняется).

## Ссылка

Кнопка «JURO» открывает роут `/clone` с тремя параметрами:

```
https://adlauncher.gcamazingtool.xyz/clone?partner=br&mode=juro&ids=<campaignId1>,<campaignId2>,...
```

Локально (dev): `http://localhost:3000/clone?partner=br&mode=juro&ids=...`

## Параметры

| Параметр  | Обяз. | Что это |
|-----------|-------|---------|
| `ids`     | да    | Facebook **campaign ID** кампаний-источников (числовые ID — те же, что в Ads Manager / LION / вашей статистике), через запятую. Порядок сохраняется, дубли игнорируются. Максимум **30** источников. |
| `partner` | да    | Всегда `br` — JURO живёт только на HS-борде. (`in` = MO-клонер, там JURO нет.) |
| `mode`    | да    | Всегда `juro` — борд откроется сразу в режиме JURO. Без него откроется тот режим, который байер выбирал в прошлый раз. |

**Больше ничего передавать не нужно.** Никаких бюджетов, гео, креативов или имён — лаунчер
получит всё сам по ID источников.

## Как открывать

Обычный GET-переход. Рекомендуется новая вкладка, чтобы ваш инструмент не закрывался:

```html
<!-- один клик по строке кампании -->
<a href="https://adlauncher.gcamazingtool.xyz/clone?partner=br&mode=juro&ids=120210000000101"
   target="_blank" rel="noopener">JURO</a>
```

```js
// массовый JURO по выбранным строкам
const ids = selected.map(c => c.campaignId).join(",");
const url = `https://adlauncher.gcamazingtool.xyz/clone?partner=br&mode=juro&ids=${encodeURIComponent(ids)}`;
window.open(url, "_blank", "noopener");
```

## Примеры

```
# одна кампания
/clone?partner=br&mode=juro&ids=120210000000101

# несколько
/clone?partner=br&mode=juro&ids=120210000000101,120210000000102,120210000000103
```

## Важные нюансы

- **Авторизация.** Лаунчер за логином (тот же аккаунт Amazon Tools). Байер должен быть
  **уже залогинен** в `adlauncher.gcamazingtool.xyz`. Если сессии нет — его отправит на
  `/login`, и параметры ссылки при этом **теряются** (сохранение через `?next=` пока не
  сделано). Убедитесь, что байер залогинен заранее.
- **ID — это кампания, не адсет/объявление.** Передавайте именно `campaign_id`.
- Если у вас уже есть кнопка **Clone** на HS (`partner=br`) — JURO это **та же ссылка**
  плюс `&mode=juro`. Ничего больше менять не надо.

## Что происходит на нашей стороне (для понимания)

1. `/clone?partner=br&mode=juro` открывает HS-борд с переключателем режимов, JURO уже выбран;
   каждая переданная кампания = строка-источник на борде.
2. Байер выбирает профиль/аккаунт/пиксель, число копий и канал (LION API / FB Token),
   при желании правит имя/бид/таргетинг — и жмёт **Fire**.
3. JURO читает **посты фанки источника** и создаёт новую кампанию с ads на странице поста —
   без Page-бинда; прогресс виден в HS Task Manager.
